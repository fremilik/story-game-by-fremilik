# (Story Game Project)

Hello everyone 👋, I am creating this game project to gain more experience using the Godot Game engine. I have not decided on a name yet for this project 😅, later on i will. I also want to share this experience with you guys whether your from the Godot community or someone looking at how Game Dev works.

Am working on this project alone and my expertise are on coding, so things like art and music, i source those assets online. Everything done in this game is all me and no code is generated by AI 🤖. I am not saying I disregard the use of AI for anyone but I want the people i share this with and myself to gain a genuine experience. If you have any questions, details you feel i should implement or bugs you've noticed, you can reach out to me 🙂

This Project is way ahead of my post but I still want to share the processes I've gone through. You can find more details about the game in the Documents folder.
